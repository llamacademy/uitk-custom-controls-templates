# UI Toolkit Custom Controls and Templates

In this tutorial repository and [accompanying video](https://youtu.be/_FlgT0bB_pY) you will learn how (and when) to make custom controls and templates in UI Toolkit.

[![Youtube Tutorial](./Video%20Screenshot.jpg)]([https://youtu.be/_FlgT0bB_pY](https://youtu.be/aZmupJcIUp4))

If you want a guided introduction to UI Toolkit, consider my [UI Toolkit Foundations Course](https://gamedev.tv/courses/unity-ui-toolkit-fundamentals?ref=mjuzyjq&utm_source=llamacademy&utm_medium=github&utm_campaign=unityscape-uitk), where you'll learn the basics of UI Builder, UXML, USS, Data Binding, Animation in UI Toolkit, and more!
